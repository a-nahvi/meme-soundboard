# Meme Soundboard

Use the project's GitHub repository as the sole publication channel for every new version. Publish the source, Windows installer, and matching update manifest using the release instructions in [README.md](README.md#publish-a-release).

Keep the licensed Iconly source local. Keep the generated atlas in the ignored `assets/iconly/` directory and build the official installer with `-WithIconly` to embed the rendered frames.
